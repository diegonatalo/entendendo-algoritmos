### 🧪 Testes

```bash
pnpm test
```

Usa [Vitest](https://vitest.dev). Os testes cobrem a lógica de todos os capítulos em `lib/` (ordenação, grafos, recursão, tabela hash, programação dinâmica), a lista de capítulos (rotas e metadados) e os trechos de código mostrados nas páginas, que são executados e comparados com as funções reais.

Para reexecutar ao salvar: `pnpm test:watch`.
